# 모바일 프로그래밍 개인 프로젝트 제안서

## 1. 프로젝트명

AI 기반 식단 기록 관리 앱

## 2. 프로젝트 개요

본 프로젝트는 사용자가 식사 정보를 간단하게 기록하고 관리할 수 있도록 돕는 모바일 앱을 개발하는 것을 목표로 한다. 사용자는 음식명을 직접 입력하거나 음식 사진을 선택하여 식단 기록을 작성할 수 있다.

음식 사진을 선택한 경우, 사용자는 AI 분석 버튼을 눌러 사진 기반 음식명과 칼로리 추정 결과를 받을 수 있다. AI가 추정한 결과는 그대로 저장되는 것이 아니라, 사용자가 직접 확인하고 수정한 뒤 저장할 수 있도록 설계한다.

본 앱은 대규모 상용 식단 관리 서비스가 아니라, 개인이 일상적으로 사용할 수 있는 단순하고 실용적인 식단 기록 기능에 초점을 둔다. 따라서 핵심 기능을 중심으로 범위를 제한하고, 학기 내에 완성 가능한 수준의 모바일 앱을 구현하는 것을 목표로 한다.

## 3. 기획 배경 및 필요성

식단 기록은 개인의 건강 관리, 체중 관리, 식습관 개선에 도움이 되는 중요한 활동이다. 사용자가 하루 동안 어떤 음식을 얼마나 섭취했는지 기록하면 자신의 식습관을 더 쉽게 파악할 수 있고, 목표 칼로리와 실제 섭취량을 비교하며 생활 습관을 조정할 수 있다.

그러나 매 식사마다 음식명과 칼로리를 직접 입력하는 방식은 번거롭고, 사용자가 기록을 중단하게 만드는 원인이 될 수 있다. 특히 음식의 대략적인 칼로리를 직접 찾아 입력해야 하는 과정은 사용자에게 부담이 된다.

이미지 기반 AI 분석 기능을 활용하면 사용자가 음식 사진을 선택한 뒤 음식명과 칼로리 추정 결과를 받을 수 있어 입력 부담을 줄일 수 있다. 다만 본 프로젝트에서는 복잡한 영양소 분석이나 상용 서비스 수준의 추천 기능까지 확장하지 않고, 식단 기록에 필요한 핵심 기능을 중심으로 작고 현실적인 범위를 유지한다.

## 4. 주요 기능 계획

- 홈 화면: 오늘 섭취 칼로리, 기록 개수, 목표 칼로리 표시
- 음식 추가 화면: 음식명, 칼로리, 메모 직접 입력
- 이미지 선택 기능: 음식 사진 첨부 및 미리보기
- AI 분석 기능: 사진 기반 음식명/칼로리 추정
- 식단 기록 리스트 화면: 저장된 음식 기록을 LazyColumn으로 표시
- 식단 상세 화면: 음식 정보, 사진, 메모, AI 분석 결과 확인
- 내 정보 화면: 닉네임, 목표 칼로리, 목표 유형 설정

## 5. 화면 구성 계획

계획 중인 주요 화면은 다음과 같다.

1. HomeScreen
2. AddMealScreen
3. MealListScreen
4. MealDetailScreen
5. ProfileScreen

각 화면은 Jetpack Compose와 Navigation Compose를 사용하여 연결할 예정이다. 최소 4개 이상의 화면 전환 요구사항을 충족하기 위해 다음과 같은 흐름을 계획한다.

- HomeScreen → AddMealScreen
- HomeScreen → MealListScreen
- MealListScreen → MealDetailScreen
- HomeScreen → ProfileScreen
- AddMealScreen → 저장 후 HomeScreen 또는 MealListScreen

## 6. 기술 스택 계획

- Kotlin
- Jetpack Compose
- Navigation Compose
- Room Database
- Image Picker
- AI 분석 모듈

AI 분석 기능은 음식 사진을 기반으로 음식명과 칼로리를 추정하는 모듈로 구성할 계획이다. 첫 번째 구현 버전에서는 실제 외부 AI API 연동 전에 모의 AI 분석기를 사용하여 앱 흐름과 UI 동작을 먼저 검증할 수 있다.

이후 개발 상황에 따라 Gemini 또는 OpenAI Vision API와 같은 실제 AI API로 교체할 수 있다. 외부 API를 사용하는 경우 API 키는 코드에 직접 하드코딩하지 않고, 별도의 안전한 설정 방식으로 관리할 예정이다.

## 9. 범위 제한

본 프로젝트는 학기 내에 완성 가능한 핵심 기능 중심의 식단 기록 앱을 목표로 하므로, 다음 기능은 구현 범위에서 제외한다.

- 카카오 로그인
- 네이버 로그인
- Firebase Auth
- 지도 기능
- 친구 공유 기능
- 복잡한 영양소 분석
- 운동 기록 기능
- 상용 서비스 수준의 추천 알고리즘

위 기능들은 프로젝트 규모를 과도하게 확장할 수 있으므로 제외한다. 대신 식단 기록, 이미지 선택, AI 기반 음식 분석, 데이터 저장 및 조회라는 핵심 흐름을 안정적으로 구현하는 데 집중한다.

## 10. 기대 효과

본 앱을 통해 사용자는 매일의 식사 정보를 더 쉽게 기록할 수 있다. 직접 입력과 사진 기반 AI 분석을 함께 제공하여 사용자가 상황에 맞게 기록 방식을 선택할 수 있고, AI 추정 결과를 수정한 뒤 저장할 수 있어 실용성을 높일 수 있다.

기술적으로는 Jetpack Compose 기반 화면 구성, Navigation Compose를 활용한 화면 전환, LazyColumn 기반 리스트 UI, 이미지 처리, Room Database, AI 관련 기능을 종합적으로 다룰 수 있다.

프로젝트 범위가 작고 명확하기 때문에 한 학기 안에 완성 가능하면서도, 모바일 프로그래밍 개인 프로젝트에서 요구하는 주요 기술 조건을 충족할 수 있을 것으로 기대한다.
